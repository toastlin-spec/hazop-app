# 製程安全評估 App（第 4 階段，完整版）

離線單機網頁 App，協助職安管理師進行危險性工作場所製程安全評估（初步危害分析 × HAZOP）。
不需安裝、不連網、資料只存在你的電腦。

## 線上版

https://toastlin-spec.github.io/hazop-app/

線上版與下載版功能相同；資料一樣只存在你自己的瀏覽器與電腦，不會上傳到任何伺服器。

## 開啟方式（下載版）

1. 把整個 `hazop-app` 資料夾放到電腦任一位置（例如「文件」）。
2. 用 **Chrome 或 Edge** 開啟資料夾裡的 `index.html`（右鍵 →「開啟檔案」→ 選 Chrome／Edge）。
3. 第一次使用可按右上「載入範例」看填寫示範；正式評估請按「新專案」。

## 資料保存

| 方式 | 說明 |
|---|---|
| 自動保存 | 每次修改都會自動存在瀏覽器裡，關掉再開會還原。只存在這台電腦的這個瀏覽器。 |
| 儲存（Ctrl+S） | 存成 `.hazop.json` 專案檔，可備份、寄給同事、下次用「開啟…」讀回。 |
| 復原 | 右上「↶ 復原」可回到上一步（最多 50 步），包含誤刪的列。 |

> 建議每次評估會議結束都按一次「儲存」，把專案檔放在公司的備份位置。清除瀏覽器資料會刪掉自動保存的內容。

## 操作要點

- **黃底**＝待填欄位；**淺藍**＝自動計算。
- 檢核表 A、C 的危害／需求欄，**點一下切換**：A 是「有 → 無 → 空白」，C 是「有 → 無 → 不適用 → 空白」。用 Tab 移動、空白鍵切換也可以。
- 化學品清冊在檢核表 A、C **共用**，品名只輸入一次。
- 品名若在勞動檢查法施行細則附表一／附表二內，會自動顯示 TQ 法定限量。
- 註解欄有填寫時會自動編為「註1、註2…」。
- 判定門檻在「判定設定」：已定案 Q／TQ 多物質＝加總、壓差＝錶壓。
- **區域物質存量**：每個製程區域一張卡片，填物質與最大存量，自動查 TQ、依濃度換算純物質量、算 Σq／TQ。
- **系統作用判定**：依①～⑦條件自動判定，顯示成立的條件編號與缺漏欄位；結果分「重大潛在危害／資料不完整／—」，規則與 Excel 範本 v2 相同。壓力一律填錶壓，非真空操作的「最低操作壓力」留白。
- **HAZOP 工作表**：判為重大的區域可一鍵建立節點；每個節點有自己的設計目的、P&ID 圖號、會議資料。選引導字和參數會自動帶出偏離（依表 3.2.3-1），「批次加入」可一次產生某參數的所有偏離。風險分數＝嚴重性×可能性，等級依判定設定。
- **改善建議追蹤**：HAZOP 有填改善建議的列自動列入，和 HAZOP 是同一份資料；也可新增檢核表等其他來源的建議。可篩選未完成／逾期／高風險。逾期＝已過預定完成日且未填實際完成日（同 Excel 公式）。
- **專案總覽**：5×5 風險矩陣熱圖（點格子看明細）、改善建議完成與逾期統計。
- **匯出 Excel**：與範本 v2 相同版面，保留公式、下拉選單、條件式顏色；每個 HAZOP 節點一張工作表；改善建議彙整中 HAZOP 來源以公式連到 HAZOP 工作表。列數依資料延伸並保留空白列可續填。
- **從 Excel 匯入**：可讀原始範本（v1）、範本 v2、本 App 匯出檔。灰底範例列預設略過；檢核表 A、C 同名化學品合併；HAZOP 依節點欄分組；彙整表的 HAZOP 項目併回對應列（兩邊不一致時以彙整表為準並提示）。原始範本的 Q／TQ 與真空欄定義不同，會記在區域備註並提醒補填。
